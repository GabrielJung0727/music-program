# Mono 디자인 규칙

이 폴더(`src/Mono.Web`)의 화면은 전부 이 문서의 값만 쓴다. 값의 원본은 `src/styles/tokens.css` 이고,
컴포넌트에는 색·반지름·시간을 직접 적지 않는다. 규칙을 바꿀 때는 이 문서와 토큰을 같이 고친다.

기준으로 삼은 화면: 구조와 여백은 스포티파이 데스크톱(커버 색 헤더, 왼쪽 고정 라이브러리),
재생 화면의 어두운 캔버스와 가사 타이포그래피는 YouTube Music, 신호 경로는 Roon.

## 1. 색

### 어두운 테마 (기본)

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg-0` | `#0B0B0D` | 캔버스 |
| `--bg-1` | `#131316` | 사이드바, 패널, 플레이어 바 |
| `--bg-2` | `#1B1B20` | 카드, 호버 |
| `--bg-3` | `#25252C` | 카드 위의 입력·호버 (파생) |
| `--bg-4` | `#31313A` | 눌림, 꺼진 토글 (파생) |
| `--fg-0` | `#F4F4F6` | 본문, 제목 |
| `--fg-1` / `--fg-2` / `--fg-3` | `#A8A8B3` / `#777783` / `#4E4E58` | 보조 · 메타 · 비활성 (파생) |
| `--accent` | `#6D6DF6` | 활성 메뉴, 주요 재생 버튼, 진행 바, 초점 |

### 밝은 테마

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg-0` | `#F6F6F8` | 배경 |
| `--bg-2` | `#FFFFFF` | 카드 |
| `--bg-1` | `#ECECEF` | 보조 표면 (사이드바, 플레이어 바) |
| `--bg-3` / `--bg-4` | `#E3E3E8` / `#D4D4DB` | 입력·호버 · 눌림 (파생) |
| `--fg-0` | `#111114` | 본문 |
| `--fg-1` | `#5C5C66` | 보조 |
| `--fg-2` / `--fg-3` | `#8B8B96` / `#B9B9C2` | 메타 · 비활성 (파생) |
| `--accent` | `#5252E0` | 포인트 |

"파생"은 확정 값 사이를 메우려고 같은 무채색 계열에서 고른 값이다.

### 오디오 상태색

브랜드색과 섞어 쓰지 않는다. 한 색은 한 가지 뜻만 가진다.

| 토큰 | 값 | 뜻 |
| --- | --- | --- |
| `--ok` | `#22C55E` | Bit-Perfect 정상 출력, 연결됨, 클럭 잠김 |
| `--warn` | `#F59E0B` | DSP 활성 · 리샘플링 개입. 그 밖의 곳에는 쓰지 않는다 (Core 재연결 안내만 예외) |
| `--live` | `#EF4444` | On Air. 빨간 점 또는 빨간 배지 |

밝은 테마에서 글자로 쓸 때는 `--ok-text #15803D`, `--warn-text #B45309`, `--live-text #DC2626`.
램프(점)는 두 테마에서 같은 색이다.

### 색 규칙

- 섀시는 무채색이다. 화면의 색은 앨범 커버에서 나온다.
- 커버 색 헤더(`.tint`): 커버에서 가장 넓게 깔린 색상을 뽑아 채도 ≤ 42%, 명도 19%(밝은 테마 86%)로 누른다.
  위에서 깔려 340px 지점에서 절반으로 옅어지고, 572px 에서 캔버스 색이 된다.
- 지금 재생 화면은 테마와 무관하게 어두운 캔버스다. 커버 색은 위쪽 58% 에만 번진다.
- 장식용 그라데이션, 흐린 커버 배경은 쓰지 않는다.

## 2. 글꼴

| 역할 | 글꼴 | 굵기 · 자간 |
| --- | --- | --- |
| 제목·디스플레이 (인사말, 앨범명, 라운지 제목, 가사) | Plus Jakarta Sans + Wanted Sans | 700–800, `-0.03em` |
| 본문·UI | Inter + Pretendard | 400–640 |
| 오디오 규격·숫자 (`24/96`, `FLAC`, 트랙 번호, 시간) | JetBrains Mono | `tabular-nums` |

| 단계 | 크기 / 줄높이 | 굵기 |
| --- | --- | --- |
| display | 44 / 1.08 | 800 |
| h1 | 30 / 1.15 | 800 |
| h2 | 19 / 1.25 | 700 |
| h3 | 15 | 620 |
| body · small · cap | 14 / 1.45 · 13 · 12 | 400 |
| label | 11.5 | 640, 자간 0.045em |
| 가사 (지금 재생 화면 / 패널) | 30 / 1.3 · 19 / 1.4 | 800 · 700 |

- 글꼴 파일은 전부 번들에 싣는다(`@fontsource-variable/*`, `wanted-sans`, `pretendard`). 오프라인에서도 같은 모습이어야 한다.
- 제목 글꼴은 한글 띄어쓰기가 좁아 보여서 `word-spacing: 0.06em` (가사는 `0.08em`)을 준다.
- 고정폭은 숫자와 규격 문자열에만 쓴다. 한글 문장에는 쓰지 않는다.

## 4. 움직임

모션은 아래 다섯 군데뿐이다. 다른 곳에 새로 만들지 않는다. 호버는 색만 120ms 동안 바뀐다.

| # | 지점 | 토큰 | 값 | 동작 |
| --- | --- | --- | --- | --- |
| 1 | 재생 시작 | `--m-play` | `140ms cubic-bezier(0.2, 0, 0, 1)` | 재생 버튼 아이콘 전환. 재생 중인 행 왼쪽에 2px 인디고 표시가 밀려 들어온다. 이퀄라이저 막대는 움직이지 않는다 |
| 2 | 지금 재생 화면 | `--m-np` | `260ms cubic-bezier(0.22, 1, 0.36, 1)` | 하단 바에서 위로 펼쳐진다 |
| | 커버 색 번짐 | `--m-tint` | `400ms ease-out` | 곡이 바뀌면 배경 색이 번지듯 바뀐다 |
| 3 | 방송 시작 | `--m-ring` | `500ms ease-out` | On Air 배지에서 링이 한 번 퍼진다. 반복하지 않는다 |
| 4 | 가사 | `--m-lyric` | `320ms cubic-bezier(0.25, 1, 0.5, 1)` | 지금 소절 `opacity 1` · `scale(1.02)` (기준점 왼쪽 가운데), 나머지 `opacity 0.35`. 가운데 정렬 스크롤도 같은 곡선 |
| 5 | 우측 패널 | `--m-panel` | `220ms cubic-bezier(0.2, 0, 0, 1)` | 본문을 밀어내며 너비가 늘어난다 |
| | 신호 경로 팝오버 | `--m-pop` | `160ms ease-out` | 아래에서 위로 펼쳐진다 |

## 5. 부품

### 신호 경로

- 플레이어 바의 칩: 램프 + `24/96 · BIT-PERFECT`. DSP 나 SRC 가 걸리면 램프가 초록에서 앰버로 바뀐다.
- 팝오버: 머리말 `신호 경로: 무손실 / 가공됨`, 그 아래 출력 장치 이름.
- 왼쪽에 1px 실선 레일, 단계마다 30px 고리(테두리 1.5px). 소스 고리 안에는 컨테이너 이름(`FLAC`).
- 큰 단계(소스 · Mono Core · 출력)는 고리, 끼어드는 변환(SRC, 꺼진 DSP)은 레일 위의 7px 점.
- 단계 이름 옆의 6px 점이 그 구간의 상태. 규격 줄은 `--accent-text`.

### 라운지 표지

- 비율 3:2. 지금 곡 커버가 왼쪽 2/3 에 정사각형으로, 다음 두 곡이 오른쪽에 위아래로 놓인다.
- 같은 앨범이 이어지면 건너뛰고 앨범이 달라지는 곡의 커버를 쓴다. 서로 다른 커버가 셋이 안 되면 남은 칸에 남은 곡 수를 적는다.
- 재생 중인 곡이 없는 방: 호스트 이름에서 뽑은 두 색의 패턴(사선·점·격자 중 하나) + 호스트 아바타.
- 오른쪽 아래에 `ON AIR` 배지 · 청취자 수(`32명`) · 음질(`24/96`).
- 커버와 지금 곡은 `list_rooms` 의 `covers` · `nowTitle` · `nowArtist` · `upcoming` 에서 온다. 이 필드가 없는 예전 Core 에서는 패턴 표지로 그린다.

### 크레딧

태그의 `이름 — 역할` 줄을 이름·역할 두 칸으로 나눠 그린다. 구분 기호는 화면에 내보내지 않는다.

## 6. 문구

- 화면 문구는 한국어. 제품 용어(Bit-Perfect, Hi-Res, DSD, On Air)만 영어로 둔다.
- 엠대시(—)로 문장을 잇지 않는다. 마침표로 끊거나 가운뎃점(·)으로 나열한다.
- 이모지를 아이콘 대신 쓰지 않는다. 아이콘은 `lucide-react` 한 벌. 라운지의 반응 버튼만 예외다
  (Core 가 허용 이모지 목록을 내려 준다).
- 없는 정보를 지어내지 않는다. Core 에 근거가 없는 표기("DR 13", "Analog Master Transfer")는 쓰지 않는다.
