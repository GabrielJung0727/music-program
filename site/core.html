Core

집에서 Mono를 돌리는 가장 완전한 방법.

도서관, 클럭, DSP의 허브.

Mono.Core.exe는 헤드리스입니다. 창이 없고, Control이 없으면 자동으로 기동됩니다. 라이브러리 스캔, 메타데이터 그래프, 룸, MATP 마스터 클럭을 한 프로세스가 책임집니다.

다운로드 ⟶

Control

유일한 사용자 창. Avalonia 네이티브 GUI. 사이드바 + 본문 + 하단 플레이어 바. 소리는 내지 않습니다.

Core

백그라운드 서비스. TCP 7700, MATP 7701, 아트 API 7702. 트레이에서 숨습니다.

Output

엔드포인트. 존에 붙을 때 Control이 기동합니다. DAC가 있는 기계에서만 돌리면 됩니다.
