# Mono 구현 현황

[`01-기획명세서.md`](01-기획명세서.md)의 기능 표를 기준으로, 지금 코드가 어디까지 왔는지와 남은 한계를 적는다.
✅ 동작 · 🟡 동작하되 범위 제한 · ⬜ 미구현

## 1. 핵심 기술

| 기능 | 상태 | 구현 위치 · 비고 |
| --- | --- | --- |
| 초저지연 음원 공유 | ✅ | `FanOutService`(lookahead 320ms) + Output 지터 버퍼. 같은 호스트 Exclusive 실측 offset −0.16ms / jitter 0.33ms |
| MATP | ✅ | `MatpFrame`(44B 헤더 + AES-GCM), 컨트롤/데이터 플레인 분리, `epoch`로 리싱크 |
| 마스터 클럭 · 멀티 엔드포인트 | ✅ | `ClockSync`(offset·rtt·지터 추정, 적응형 버퍼 5–80ms), Output → Core `clock_report` |
| Bit-perfect 경로 | ✅ | DSP Off·Audiophile에서 입력 그대로 전달. 하드웨어 볼륨 우선, 디지털 감쇠는 정책이 막음 |
| 고해상도 DSP | ✅ | `DspPipeline`: 업샘플·틸트·크로스피드·Easy EQ·Device EQ·Speaker·headroom. **룸 IR WAV/ZIP 로딩·컨볼루션** |
| 메타데이터 그래프 | ✅ | `CatalogStore.Graph` — 아티스트·앨범·트랙·크레딧·연관/동시대 아티스트, 전부 로컬 쿼리 |
| 고성능 로컬 카탈로그 | ✅ | SQLite + 인덱스, 메모리 그래프 캐시 (`catalog.db`) |
| 스마트 선택형 오토플레이 | ✅ | `RoomManager.ProposeAutoplayCandidates`(큐 마지막 곡 종료 40초 전 후보 3곡) + `ChooseAutoplay` + `AdvanceFinished`가 선택/1번 후보로 자동 전환 |
| 다국어 아티스트 검색 | ✅ | `Artist.AlternateNames` + `aliases.json`(mbid 포함) + MusicBrainz opt-in (`MONO_MUSICBRAINZ=1` / `POST /api/aliases/musicbrainz`) |
| 위키백과 아티스트 이력 | ✅ | `WikipediaService` — ko→en 폴백, 정식명+별칭을 표제어 후보로 순차 시도, 메모리+파일(`data/wiki`) 캐시 30일. `/api/wiki/{artistId}` |

| 라운지 생성/참여 | ✅ | 4개 모드, 초대 코드 발급/연장/폐기, 최대 인원, 능력 협상 실패 시 사유 표시 |

| 동기화 가사 | ✅ | `LyricsParser` + Control에서 `media_time` 따라 하이라이트·자동 스크롤 |
| 세션 아카이브 | ✅ | 종료 시 동의 → SQLite 영속화. 미동의 시 휘발. 익명화·보존기간 정책 반영 |
| 세션 → 플레이리스트 | ✅ | 핀/♥ 기준 하이라이트 플레이리스트 자동 생성, M3U 내보내기(`/api/m3u/{id}`) |
| 청음 히스토리 | ✅ | `HistoryStore` 개인 타임라인, 완청 표시, 히스토리에서 큐로 다시 싣기 |

## 5. 비기능 요구사항

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 음질(소셜이 오디오를 흔들지 않을 것) | ✅ | 소셜은 컨트롤 세션, 오디오는 MATP. Output도 수신/렌더 루프 분리 |
| 동기화 < 5ms | 🟡 | 같은 호스트 Exclusive에서 sub-ms 락 확인. `sync_probe.verdict`로 다중 Output 목표 판정. **타 기기 실측은 현장** |
| 확장 (Core 1 : Control N : Output M) | ✅ | Control 없이 Output+Core만으로도 재생 지속(자동 다음곡 포함) |
| 보안 | ✅ | 팬아웃 페이로드 AES-GCM, 원격 Control 페어링 토큰, 파일은 피어에 재배포하지 않음 |
| 라이선스 분기 | ✅ | 스트리밍은 자동으로 Clock-sync, 팬아웃은 로컬 파일에 한정 |

## 6. 남은 한계 (다음 작업 후보)

1. **디코더 메모리**: ✅ Media Foundation 경로가 **구간 seek 디코드**로 바뀜 (`MediaFoundationSlicer`, Output `MfStreamingLocalRenderer`). 전량 RAM 적재 제거.
2. **DSD 렌더**: ✅ Fan-out DoP + Clock-sync `DsfLocalRenderer`(DoP). ASIO는 `--asio` 플래그로 선택(`AsioAudioRenderer`). **실 DAC에서 네이티브 DSD·채널 정합 청음 검증**은 기기 의존.
3. **스트리밍 SDK**: ✅ env `MONO_TIDAL_CLIENT_ID`/`SECRET`, `MONO_QOBUZ_APP_ID`/`SECRET` 있으면 실 OAuth·즐겨찾기 import·스트림 URL 해석. 없으면 데모 폴백. **파트너 승인·실계정 QA** 필요.
4. **Avalonia UX**: Home 레일·Genres·Now Playing·Easy EQ·시그널 패스·트레이·다크모드·Velopack 업데이트 UI 반영. Roon 전 기능 패리티는 범위 밖.
5. **LAN 다중 엔드포인트 검증**: ✅ `sync_probe`에 `verdict`(offsetSpread·meetsTarget&lt;5ms·안내 문구). **물리 기기 2대+ 실측**은 현장에서 `Sync Probe`로 확인.
6. **다국어 검색 확장**: ✅ `aliases.json`의 `mbid` 인식 + `POST /api/aliases/musicbrainz` / `MONO_MUSICBRAINZ=1` 시 MusicBrainz aliases 병합.
7. **Zone Independent 모드**: ✅ 로직 + 단위 테스트(기기별 다른 큐). 물리 2기기 시나리오는 현장 확인.
8. **앨범 아트 60fps**: ✅ `ArtCache` LRU·`DecodeToWidth(160)`·로드 평균 ms 계측(`ArtPerfText`). 대형 그리드 실측 수치는 기기별.
9. **라이너 노트 스크롤 동기**: ✅ `linerScrollY` + `follow_host` 스냅샷 추종 (픽셀 단위).
