# Mono 구현 현황

[`01-기획명세서.md`](01-기획명세서.md)의 기능 표를 기준으로, 지금 코드가 어디까지 왔는지와 남은 한계를 적는다.

✅ 동작 · 🟡 동작하되 범위 제한 · ⬜ 미구현

**「Core」는 서버 로직이 있는지, 「GUI」는 `Mono.Control.exe` 에서 사용자가 실제로 도달할 수 있는지다.**
둘을 나눈 이유: 이전 판에서 Core 에만 있고 화면이 없는 기능이 ✅ 로 적혀 사실과 어긋났다.
2026-09-06 감사 기준 — 선언된 커맨드 89개 중 85개가 XAML 에 바인딩돼 있고,
나머지 4개 중 3개(`ApplyVolume` · `SeekTo` · `ExportM3u`)는 코드비하인드·데이터템플릿에서 호출된다.
도달 불가였던 `ToggleFollowHost` 는 죽은 코드라 지웠다(기능은 체크박스로 도달 가능).

## 1. 핵심 기술

| 기능 | Core | GUI | 구현 위치 · 비고 |
| --- | --- | --- | --- |
| 초저지연 음원 공유 | ✅ | ✅ | `FanOutService`(lookahead 320ms) + Output 지터 버퍼. 같은 호스트 Exclusive 실측 offset −0.16ms / jitter 0.33ms. 하단 바에 sync 배지 |
| MATP | ✅ | — | `MatpFrame`(44B 헤더 + AES-GCM), 컨트롤/데이터 플레인 분리, `epoch`로 리싱크. 전송 계층이라 GUI 대상 아님 |
| 마스터 클럭 · 멀티 엔드포인트 | ✅ | ✅ | `ClockSync` + Output → Core `clock_report`. 시그널 패스 팝오버에 offset·jitter |
| Bit-perfect 경로 | ✅ | ✅ | DSP Off·Audiophile에서 입력 그대로. 하단 바 `Bit-perfect` 배지, 볼륨 잠금 사유 표시 |

| 메타데이터 그래프 | ✅ | ✅ | `CatalogStore.Graph`. 라운지 「뮤지션 관계도」에서 탐색·따라가기 |

**호스트가 아니면 관리자 UI를 숨기지 않는다.** 비활성 + `"호스트만 바꿀 수 있습니다"` 툴팁으로 노출하고,
Core 가 독립적으로 `only host` 로 거부한다(2피어 실측 확인).

## 5. 비기능 요구사항

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 음질(소셜이 오디오를 흔들지 않을 것) | ✅ | 소셜은 컨트롤 세션, 오디오는 MATP. Output도 수신/렌더 루프 분리 |
| 동기화 < 5ms | 🟡 | 같은 호스트 Exclusive에서 sub-ms 락 확인. **타 기기 실측은 현장** |
| 확장 (Core 1 : Control N : Output M) | ✅ | Control 없이도 Output+Core로 재생 지속 |
| 보안 | ✅ | 팬아웃 AES-GCM, 페어링 토큰, 파일 재배포 없음. 검색 응답에서 로컬 경로 노출 제거 |
| 라이선스 분기 | ✅ | 스트리밍은 자동 Clock-sync, 팬아웃은 로컬 파일 한정 |

## 6. 남은 것

코드로 해결되지 않는 것들이다 — 현장·계약·하드웨어가 필요하다.

1. **코드 서명 인증서.** 현재 릴리스는 서명되지 않아 설치 시 SmartScreen 경고가 뜬다.
   `publish.ps1` 은 `MONO_SIGN_PFX_BASE64` 시크릿이 있으면 서명하도록 준비돼 있다.
2. **Tidal/Qobuz 파트너 키.** 발급 후 실 OAuth·스트림 재생 QA.
3. **LAN 2기기 실측.** 서로 다른 PC의 Output 두 대에서 `sync_probe` 의 `meetsTarget=true` 확인.
4. **ASIO 드라이버·네이티브 DSD DAC 청음.**
5. **세션 보존 기간 UI.** Core 는 집행하지만 GUI 에서 값을 바꿀 수 없다.
6. **화면 육안 검증.** 1–5단계의 새 화면은 빌드·기동·프로토콜 실측으로 확인했고,
   레이아웃은 하단 바를 제외하면 사람이 아직 보지 않았다.
