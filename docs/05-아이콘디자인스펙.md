# Mono — 아이콘·앱 아이콘 디자인 스펙

`Mono.Control.exe`용 **앱 아이콘·트레이·인앱 UI 아이콘** 제작 가이드.  
비주얼 토큰은 [`04-UIUX기획서.md`](04-UIUX기획서.md) §2와 동일.

---

## 1. 브랜드 방향 (한 줄)

**고요한 hi-fi + 함께 듣기.**  
음표 클리셰·네온·글로우·이모지풍은 피한다. Roon처럼 **여백·얇은 선·단색 심볼** 위주. 포인트 컬러 `#6D6DF6`은 CTA·활성에만.

| 키워드 | 피해야 할 것 |
| --- | --- |
| 모노리스, 동시성, 음파의 “한 선”, 라운지 | 무지개 EQ, 헤드폰+하트 클립아트, 3D 메탈, 보라 글로우 |

## 2. 앱 / 트레이 아이콘 (필수)

### 2.1 `app-icon` — Mono.Control.exe

| 항목 | 스펙 |
| --- | --- |
| **이름** | `mono-app` |
| **용도** | 작업 표시줄, 창 타이틀, 설치 zip, 바로가기 |
| **포맷** | Windows `.ico` (16 / 24 / 32 / 48 / 64 / 128 / 256) + 마스터 SVG/PNG 1024 |
| **배경** | 라이트: `#1A1A1E` 또는 투명. 다크 타일에서도 읽히게 **단색 실루엣** |
| **심볼** | 소문자 **m** 워드마크를 단순화한 마크, 또는 **한 줄의 음파가 두 끝에서 만나 “하나”가 되는 곡선** (동시 청취). 글자 `mono` 전체를 아이콘에 넣지 말 것(16px에서 깨짐) |
| **여백** | 캔버스의 약 12–15% safe padding |
| **금지** | 앨범 커버 썸네일, DAC 사진, “♪” 단독 글리프 |

**디자인 설명 (프롬프트용)**  
> Flat vector app icon for a hi-fi music co-listening app named mono. Minimal mark: two soft waveform arcs converging into one horizontal line, or a geometric lowercase “m”. Palette: near-black `#1A1A1E` and soft violet `#6D6DF6` accent only on a small detail. No glow, no gradients heavier than subtle, no emoji, no headphones clipart. Works at 16×16.

### 2.2 `tray-icon` — 시스템 트레이

| 항목 | 스펙 |
| --- | --- |
| **이름** | `mono-tray` |
| **용도** | Control 최소화·트레이 종료 정책 |
| **포맷** | 16×16 / 20×20 / 24×24 PNG (라이트·다크 OS용 각 1) |
| **디자인** | `app-icon`의 **단색 실루엣**만. Windows 트레이는 단색이 유리 → `#1A1A1E`(라이트 OS) / `#F2F2F5`(다크 OS) |
| **상태(선택)** | `tray-playing`: 심볼 옆 작은 Point 점 / `tray-sync-warn`: Warn `#D9762F` 점 |

### 2.3 Core / Output (선택)

헤드리스이지만 작업관리자에 보일 수 있음.

| 이름 | 설명 |
| --- | --- |
| `mono-core` | 동일 마크 + 얇은 **원(노드)** 하나 — “허브” |
| `mono-output` | 동일 마크 + **작은 스피커/파형 끝단** — “엔드포인트” (사진 실사 금지) |

출시 zip에서는 Control만 사용자 대면 아이콘으로 강조해도 됨.

## 3. 인앱 UI 아이콘 (현재 텍스트/이모지 → SVG로 교체)

스타일: **24×24 그리드, 1.5–2px stroke, rounded caps, 단색** (`Text` / `Muted` / 활성 시 `Point`). Fill은 재생·primary만.

### 3.1 트랜스포트 (하단 바) — P0

| 아이콘 ID | 현재 | 디자인 설명 |
| --- | --- | --- |
| `transport-prev` | ⏮ | 이중 세로선 + 왼쪽 삼각형. 선 아이콘. |
| `transport-play` | ▶ | 채움 삼각형. Primary 버튼 안에서는 흰색. |
| `transport-pause` | ⏸ | 두 개의 둥근 세로 바. |
| `transport-next` | ⏭ | `prev` 미러. |
| `art-placeholder` | ♪ | 앨범 아트 없을 때: **얇은 사각형 프레임 + 중앙 작은 파형 1줄**. ♪ 글리프 사용 금지. 배경 `#ECECF8`, 심볼 `#6D6DF6`. |

### 3.2 사이드바 내비 — P1

| 아이콘 ID | 라벨 | 디자인 설명 |
| --- | --- | --- |
| `nav-home` | Home | 단순 집 실루엣 또는 **가로 레일 3줄**(홈 레일 암시). |
| `nav-genres` | Genres | 2×2 타일 그리드. |
| `nav-qobuz` / `nav-tidal` | Qobuz / TIDAL | **공식 브랜드 마크는 파트너 가이드 준수**. 자체 대체: 글자 Q / T 모노그램(출시 전 임시). |
| `nav-lounge` | 라운지 | 두 사람 실루엣이 **한 원(룸)** 안에. |
| `nav-history` | History | 시계 + 짧은 호. |
| `nav-albums` | Albums | 겹친 정사각 2장. |
| `nav-artists` | Artists | 사람 bust 1명. |
| `nav-tracks` | Tracks | 리스트 3줄 + 왼쪽 작은 노트 점. |
| `nav-playlists` | Playlists | 리스트 + 재생 삼각형. |
| `nav-audio` | Audio | 스피커 또는 시그널 체인 3노드. |
| `nav-settings` | Settings | 기어(이빨 6–8, 과하지 않게). |

### 3.3 헤더·유틸 — P1

| 아이콘 ID | 용도 | 디자인 설명 |
| --- | --- | --- |
| `action-guide` | 가이드 | 물음표 in circle. |
| `action-theme` | 테마 | 반달(해/달) 토글형. |
| `action-resync` | 리싱크 | 두 화살표가 맞물리는 sync. |
| `action-folder` | 폴더 피커 | 열린 폴더, 선만. |
| `action-scan` | 라이브러리 스캔 | 폴더 + 작은 순환 화살표. |
| `action-output` | 출력 연결 | 플러그/잭 단순화 또는 스피커+링크. |
| `action-close` | 닫기 | X, 2px stroke. |
| `action-search` | 검색 | 돋보기(워터마크 옆, 선택). |

### 3.4 Now Playing / 시그널 패스 — P1

| 아이콘 ID | 용도 | 디자인 설명 |
| --- | --- | --- |
| `np-lyrics` | 가사 탭 | 가로줄 3 + 왼쪽 인용 마크. |
| `np-artist` | 아티스트 | bust. |
| `np-credits` | 크레딧·라이너 | 문서/스크롤. |
| `path-source` | 시그널: 소스 | 디스크/클라우드 작은 마크. |
| `path-dsp` | 시그널: DSP | EQ 막대 3개(높이만 다름). |
| `path-device` | 시그널: 출력 | 스피커. |
| `badge-bitperfect` | Bit-perfect | 작은 체크 in 캡슐(아이콘+텍스트 병행). |
| `badge-processed` | Processed | 물결/필터. |

### 3.5 DSP / Audio 설정 — P2

| 아이콘 ID | 용도 | 디자인 설명 |
| --- | --- | --- |
| `dsp-off` | Off | 슬래시 원. |
| `dsp-headphones` | Headphones | 헤드폰 측면 실루엣. |
| `dsp-speakers` | Speakers | 북쉘프 1개. |
| `dsp-roomir` | Room IR | 방 평면도 + 파동. |
| `dsp-crossfeed` | Crossfeed | L/R이 가운데로 합쳐지는 두 곡선. |
| `dsp-eq` | Easy EQ | 슬라이더 5개 미니. |
| `dsp-device-eq` | Device EQ | 헤드폰 + 곡선. |

### 3.6 라운지 반응 — P2 (이모지 유지 가능)

프로토콜이 ❤️🎉👏🔥 화이트리스트라 **이모지 유지**가 안전.  
커스텀 시: 동일 의미의 **단색 24px** (하트 / 폭죽 단순형 / 박수 / 불꽃). 채도 과한 스티커풍 금지.

### 3.7 Genres 타일 배경(패턴) — P2

아이콘보다 **텍스처/모티프**에 가깝다. 각 타일 우하단에 반투명 심볼.

| 타일 | Accent (현행) | 모티프 |
| --- | --- | --- |
| Hi-Res | `#1F4E5F` | 파형 + “96” 작은 타입 |
| DSD | `#5C3D2E` | 1-bit 계단/펄스 |
| Jazz | `#3D4F5F` | 색소폰 실루엣(과하게 디테일 X) |
| TIDAL / Qobuz | 브랜드 가이드 | 공식 또는 모노그램 |
| Local | `#3A4A3A` | 폴더/디스크 |

## 4. 납품 체크리스트

```
assets/icons/
  app/mono-app.ico
  app/mono-app-1024.png
  app/mono-app.svg
  tray/mono-tray-light.png
  tray/mono-tray-dark.png
  ui/*.svg          # 24×24 viewBox, currentColor
```

| 규칙 | 내용 |
| --- | --- |
| SVG | `viewBox="0 0 24 24"`, stroke=`currentColor`, fill 없음(재생 제외) |
| 네이밍 | kebab-case, 위 ID와 동일 |
| 라이선스 | 자체 제작 또는 상용 무제한. Font Awesome 기본 세트만으로 브랜드 대체하지 말 것 |
| Avalonia | `.ico` → `ApplicationIcon` / 창 `Icon`. SVG → `PathIcon` 또는 `Svg.Skia` |
